with Keep searching beside it, then the Layer and Top / 3D switches, then the tray bar, then the
frame form one centred column as wide as the frame (with a minimum so the bars fit). Files:
`src/screens/workspace.css`, `stage.css`, `header.css`, `StageTop.tsx` as needed. Tests: style
tests next to the existing `stage.style.test.ts`; shots `noPageScroll` stays green.

## Task 2: 3D without the axis button, model always inside its frame

Remove `AxisGizmo` and anything only it uses (removal sweep: code, styles, tests, copy rows, board

the frame with a margin at every orbit angle (`src/viewer/fit.ts`, `scene.ts`). Test: fit keeps
the model's projected bounds inside the frame for a tall box at several angles.

`EditorStage` keeps the Layer and Top / 3D switches in the same place as the normal stage; the
editing sentence takes the status heading's place; Keep searching is absent; the tray bar's slot
